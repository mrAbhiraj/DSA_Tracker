## How to Use

1. Pick a topic folder.
2. Open the question folder.
3. Read Problem.md.
4. Write your own solution in code.py when you are ready.
5. Add a brief summary in Notes.md.
6. Update your progress in Study-Tracker.md.

## Review Rule

For every problem, keep:
- Idea
- Approach
- Time complexity
- Space complexity
- Edge cases
- One-line recall summary

This keeps the repo clean, searchable, and easy to revise before interviews.
