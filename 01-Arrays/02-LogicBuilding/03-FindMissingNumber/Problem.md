# Find Missing Number

Given a sorted array containing numbers from 1 to n except one missing number, find the missing number.

### Example:

**Input**: nums = [1, 2, 4, 5]

**Output**: 3

### Constraints:

- 1 <= nums.length <= 10^5
- nums contains unique values in sorted order

### Frequently Occurring Doubts

- What if the missing number is at the beginning or end?
- Can we solve this without using extra space?

### Interview Follow-up Questions

- How would you do this using XOR or arithmetic formulas?
- Can this be generalized for multiple missing numbers?
