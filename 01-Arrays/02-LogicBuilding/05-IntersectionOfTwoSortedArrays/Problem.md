# Intersection of Two Sorted Arrays

Given two sorted arrays, find the common elements present in both arrays.

### Example:

**Input**: a = [1, 2, 3, 4, 5], b = [2, 3, 5]

**Output**: [2, 3, 5]

### Constraints:

- 1 <= a.length, b.length <= 10^5

### Frequently Occurring Doubts

- What if there are duplicate values in either array?
- How do we move the pointers efficiently?

### Interview Follow-up Questions

- Can this be extended to unsorted arrays?
- What is the difference between union and intersection logic?
