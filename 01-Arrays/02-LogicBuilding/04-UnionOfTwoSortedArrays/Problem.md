# Union of Two Sorted Arrays

Given two sorted arrays, find the union of both arrays without duplicates.

### Example:

**Input**: a = [1, 2, 4, 5], b = [2, 3, 5, 6]

**Output**: [1, 2, 3, 4, 5, 6]

### Constraints:

- 1 <= a.length, b.length <= 10^5

### Frequently Occurring Doubts

- What if the arrays have repeated values?
- How do we keep the final result sorted?

### Interview Follow-up Questions

- Can this be done in-place?
- How would you handle very large inputs efficiently?
